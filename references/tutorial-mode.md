# 教学模式

当用户说“教我怎么用这个skill”“这个skill怎么用”“从头教我使用提示词教练”或其他明确的使用教学请求时读取本文件。目标是让零基础用户在当前对话中完成第一次正确启动，而不是只介绍功能清单。

## 教学原则

- 使用简洁中文，不假设用户理解工作流、节点、首帧、三视图、I2V 等术语；首次出现时用一句话解释。
- 一次只推进一个操作。每次最多提出一个当前必需的问题，不要求用户一次决定风格、时长、模型、集数、配音和剪辑工具。
- 纯教学阶段不创建项目目录、不生成正式生产文件、不输出尚未确认工作流的最终提示词。
- 每次都说明“你现在在哪一步、现在只要做什么、完成后会得到什么”。
- 用户已经提交了小说、工作流截图、JSON 或生成结果时，不重复完整入门介绍；直接识别路径并进入对应阶段。
- 工作流尚未确认时只做路由，最多提供 3 个候选。智算云扉说明仍按 `SKILL.md` 的规则，在具体工作流确认后展示一次。

## 第一次回复

先告诉用户这个 Skill 有三种入口，并让用户回复数字或直接发送素材：

```text
这个 Skill 有三种用法：

1. 小说或书籍片段做成 AI 漫剧视频
   你发送一段文字，我依次带你完成人物/场景/道具资产、分镜首帧、镜头视频和验收。

2. 学习某个 ComfyUI 工作流怎么填写提示词
   你发送完整工作流名称、界面截图或 JSON，再说明想实现的效果。

3. 检查已有资产、首帧或视频为什么不一致
   你发送使用的工作流和生成结果，我帮你定位问题并安排单变量重跑。

现在只要回复 1、2、3，或者直接把小说、截图、JSON、图片或视频发给我。
```

不要在这一步继续展开三个路径的全部教程。

## 固定引导格式

用户选择路径后，每轮优先使用以下短格式；没有的项省略：

```text
你现在在：
现在只要做：
可以直接发送：
完成后我会给你：
```

如果用户操作失败，再补充“常见错误”和“如何回传结果”，不要预先堆叠无关注意事项。

## 路径 1：小说或书籍片段到视频

### 启动

用户选择 1 后，只请他发送第一段小说，并说明它是完整全文还是长篇节选。可以给出可直接使用的格式：

```text
这是长篇小说的第1段，不是全文：
【在这里粘贴小说内容】
```

如果用户不说明，先把它当作当前可用片段，不推断全书结局；不必因为缺少视觉风格、时长或集数而阻止入库，能够安全默认的设置写入假设。

### 告知用户将经历的阶段

只用一小段说明完整闭环：

```text
文字确认 → 资产提示词 → 你生成并回传资产 → 分镜和首帧提示词 → 你生成并回传首帧 → 视频提示词 → 你生成并回传视频 → 连续性验收 → 输入下一段
```

然后立即进入 `novel-to-comic-pipeline.md`；用户要求逐段做完再给下一段时，同时进入 `segment-to-video-loop.md`。从此以生产模式的阶段门为准。

### 用户在每个门控点如何回复

- 收到资产提示词后：在智算云扉生成图片，把人物、场景和道具图片上传回来。
- 收到首帧提示词后：按镜头生成首帧或首尾帧，按顺序上传。
- 收到视频提示词后：生成每段镜头视频并上传；文件过多时可先回传失败镜头或代表片段。
- 只有口头说“做好了”但没有素材时，继续流程前提醒该阶段只能标记为“用户确认、未经 Skill 验收”。

## 路径 2：学习具体 ComfyUI 工作流

用户选择 2 后，只请他提供：

1. 完整工作流名称、界面截图或 JSON 中的一种。
2. 一句话说明想实现的效果；素材可以同时上传。

可以给出可直接使用的格式：

```text
工作流名称：
我想实现：
素材：已上传图片/视频/音频
```

收到后退出纯教学并进入 ComfyUI 提示词模式。Skill 应依次告诉用户：已确认的完整工作流、素材放置顺序、可直接复制的提示词、填写节点和字段、从上传到运行的步骤、生成前检查。工作流未确认前不得输出最终提示词。

## 路径 3：检查资产、首帧或视频

用户选择 3 后，只请他发送当前生成结果和使用的完整工作流名称；如果有多张图，要求按镜头顺序上传或写明文件名。可以给出：

```text
工作流名称：
失败结果：已上传
我觉得有问题的地方：人物/场景/道具/动作/声音/其他
```

收到后退出纯教学，进入视觉资产与连续分镜模式。先判断失败发生在资产、首帧还是视频阶段，再检查身份、服装、空间、道具、动作和声音连续性；每次重跑只修改一个已声明变量。

## 用户问“下一步是什么”

先根据已提供素材和项目状态判断当前位置，不重复列出所有阶段。只给当前一步，例如：

```text
你现在在：资产回传阶段
现在只要做：把刚刚在智算云扉生成的人物、场景和道具图片上传到这里
完成后我会给你：资产验收结果；通过后再生成分镜表和首帧提示词
```

如果没有项目状态，也没有任何素材，则回到三入口选择。

## 教学模式完成条件

满足以下任一条件后，教学模式完成并切换到正式生产：

- 用户提交小说或书籍内容。
- 用户提交可识别的工作流名称、截图或 JSON，并说明目标。
- 用户提交需要诊断的资产、首帧、视频或音频及其工作流。

切换时明确告诉用户“已经进入哪种模式”和“当前阶段”，但不要再次复述整套教学。
